# Reference

Use this section when you need an exact command, setting, file field, or supported feature.

The pages describe the current behavior of API Test Pilot:

- [Command line](command-line.md) lists every command and option.
- [Project configuration](project-configuration.md) defines `.api-test-pilot/config.yaml`.
- [Supported specifications](supported-specifications.md) lists the OpenAPI, Swagger, and Postman features that can be read.
- [Scenario suite](scenario-suite.md) defines the generated test file.
- [Report formats](report-formats.md) describes JSON, JUnit XML, and HTML output.
- [Environment variables](environment-variables.md) lists authentication, AI, Slack, and email settings.

For a guided first run, start with [Test a public API](../tutorials/test-a-public-api.md).
